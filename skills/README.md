# Organization skills

Skills that apply across every Burin Labs repository. Each skill is one
directory holding a `SKILL.md`, following the packaging convention Harn already
uses (`harn skill list --json`): YAML frontmatter with `name`, `short`,
`description`, and `when-to-use`, then the body.

A skill states rules. Rationale, worked examples, and per-repository paths live
in the canonical page the skill links to, so the two cannot drift into two
different answers.

| Skill | Covers |
| --- | --- |
| [`house-style`](house-style/SKILL.md) | Documentation style for every page we publish |
